# MiniRedis

A production-style educational implementation of an in-memory key-value database inspired by Redis.

## Overview

MiniRedis is built from scratch in Modern C++20 to understand how high-performance storage engines are designed and implemented.

This project focuses on software engineering principles, clean architecture, modular design, testing, and performance rather than simply recreating Redis commands.

## Project Goals

- Learn storage engine internals
- Understand software architecture
- Practice modern C++20
- Build a production-style codebase
- Follow professional Git workflow
- Implement persistence, TTL, and LRU incrementally

## Planned Features

- SET
- GET
- DELETE
- EXISTS
- SIZE
- CLEAR
- HELP
- TTL (Future)
- LRU Eviction (Future)
